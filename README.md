## ✨ Portfolio Key Features

- **Awwwards-Inspired UI/UX**: Cloud Dancer light-theme design system with hardware-accelerated cursor spotlight effects and smooth glassmorphism.
- **Interactive Achievements & Photo Gallery**: Subfolder-by-subfolder archive of hackathons (*Ideatattva Nikshatra*), data science workshops (*E-Mudhra*, *BDA Plantation*), and verified professional certificates (*Google AI Essentials*, *IBM AI*, *Agentic AI*).
- **Interactive Printable Resume**: Built-in modal popup to preview and print/download official resume.
- **Real-Time Contact Form**: Integrated AJAX submission handler connected directly to email delivery.
- **Single-File Architecture**: Self-contained HTML5, Vanilla CSS3, and JavaScript with zero external heavy bundle dependencies.
